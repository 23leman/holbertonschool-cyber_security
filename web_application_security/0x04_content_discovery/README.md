# 0x04. Content Discovery

## Description
This project focuses on web content discovery techniques used in penetration testing and bug bounty hunting. It covers directory and file fuzzing using tools such as ffuf/gobuster to identify hidden endpoints, files, and directories on a target web application.

## Tasks
This directory contains scripts and results related to content discovery tasks, including flag files obtained during fuzzing exercises and a wordlist (list_fuzz) used for enumeration.
